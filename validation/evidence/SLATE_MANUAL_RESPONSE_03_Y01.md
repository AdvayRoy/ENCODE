Inside a method:
```
int[] A = {10, 20, 30};
```

`A` is an `int[]` variable. It holds a **reference to the array object**, not the three integers directly.

The components are numbered using an **index**, starting at `0`:
```css
A[0] → 10
A[1] → 20
A[2] → 30
```

So `A[0]` means: **the component of array `A` at index `0`**.
